# 🎪 디지털 서커스 · Claude Code 인수인계

> 2026-11-21 Cowork 세션에서 정리. 원본: 노션 「디지털 서커스 · Claude Code 인수인계」 (https://app.notion.com/p/41f676e73ffb81ed95f7d7dca0b198f2)

## 1. 한 줄 요약

친한 친구와 서커스를 보다가 공연장이 무너지고, 사실 처음부터 가상세계였다는 게 드러나는 **디지털 호러 체험**. 지금은 폰 선택지형 5분 초안(v0)까지 만들었고 플레이테스트 후기를 받았다. 다음 단계는 **설계도 심화(grill me) → v1 폰 초안 → PS1~2풍 3D(PC 탐색형)** 순서다.

## 2. 작업 방식 (꼭 지킬 것)

- **방향과 판단은 사용자, 노동은 AI.** 설계도(원리·의도·형식·깨질 기저선)는 사용자가 쓴다. AI는 재료를 모으고, 질문하고, 만든다.
- **설계자 효과 주의.** 결말을 아는 사람은 이야기로 무서울 수 없다(11/14 실험에서 확인). 그래서 **실제 대사·반전·디테일은 AI가 숨겨서 쓴다.** 채팅에 반전을 미리 말하지 않는다. 스크립트는 사용자가 열어 보지 않기로 한 `script/secret/`에 둔다.
- **만들기 전에 가설부터.** 버전마다 "어느 순간이 제일 무서울까"를 사용자가 먼저 쓰고, 해 본 뒤 비교한다.
- **산출물은 한 번에 하나.** 길어지면 다음 주말로 넘긴다.
- 사용자에게는 반말, 담백하게. 처음 나오는 용어는 그 자리에서 풀어 쓴다.

### 사용자 설계도 (11/21, 원문 요약)

- **무엇이 무섭나:** 분위기 자체. 알 듯 말 듯 한 모호한 미스터리에 매혹됨. 나갈 수 없다는 절망감, 현실과 가상의 뒤섞임. 나 이외의 존재 — 알 수 없지만 위협할 수도 있을 것 같은 존재. 플레이 내내 긴장하는 서스펜스, 그러다 한 번씩 확 존재를 드러내며 공포 피크. 시각적 이미지도 적절히. '알 수 없음, 예측하기 힘듦'이 두려움으로 전환.
- **어떤 세계인가:** 가상과 현실이 뒤섞인 세계(디지털 세계·가상세계). 우리 현실조차 진짜임을 확증할 수 없다는 미묘한 암시. 가상세계와 시뮬레이션에 뿌리내리고 살아갈 미래 인류를 예측해 보는 시도. 과거의 디지털 호러. 친숙하면서도 기괴하고 생경한 컨셉.
- **동료를 어떻게 쓰나:** 함께 탈출하고 서로 돕는 동료. 갑작스러운 부재나 이상한 위치에서 나타나는 등 의구심을 아주 살짝. 메인은 계속 지지하고 함께 헤쳐 나가는 동료. 하지만 결국 그도 가짜이거나, 가상세계에 잠식된다.
- **『The Amazing Digital Circus』와 다른 점:** 서커스가 메인이 아니라, 가상세계와 환상의 세계(서커스·놀이공원)를 도입하는 차원에서만 비슷. **인공지능과 철학적 좀비, 가상세계**가 더 메인인 세계관. 더 다크한 세계관, 매혹적인 캐릭터나 직접적인 위협, 미스터리나 숨겨진 의미, 중심 서사 뼈대가 다름.
- **무서움의 핵심 (11/18):** "어딘가에 있다는 증거는 있는데 정확히 예측할 수 없을 때. 그리고 예측을 못하는 경우, 내 생명에도 위협이 가해질 때."
- **비주얼 (11/18):** low visibility = 시야를 가리는 게 아니라 옛날 게임 느낌의 조잡한 3D, 디지털 호러. 무드보드: 밝은 장난감 서커스 / 텅 빈 90년대풍 공간(패스트푸드점·쇼핑몰·밤 버스) / VHS·Y2K(무지개와 물음표 문, 체크무늬 바닥, 줄무늬 복도) / 엔딩 참고(밤 도시 위를 나는 사람, 검은 격자 공간의 빨간 카펫 위 의자). 주술 이미지(불상·부적·붕괴한 신상)를 디지털·서커스 세계에 뜬금없이.
- **어릴 때 무서웠던 것:** '친숙한 풍경에 기괴함 한 스푼'. 괴담 레스토랑 도깨비 학교(평범한 학생들이 가끔 고개를 기괴하게 털며 '이히히히!' → 결정적인 순간 도깨비로 변해 쫓아옴).

## 4. v0 — 무엇을 만들었나

- 파일: `v0/circus-v0.html` (단일 HTML, 브라우저로 바로 열림) · 공개본: [claude.ai 아티팩트](https://claude.ai/artifact/KdAyXJnYMyMAo2cwawXqvv)
- 구조: 120×150 저해상도 캔버스 + VHS 오버레이 + 타자기식 대사 + 선택지(일부 시간 제한) + WebAudio 합성음(칼리오페 왈츠, 박수, 험, 슥슥, 스팅어, 심장박동)
- 흐름: 따뜻한 관람(서아·팝콘) → 단장 멘트 반복·음악 조가 틀어짐·관객 동기화 → 천막이 벗겨지며 초록 격자 공간 → 무대 뒤 복도(불상·입장권 '4,118회째'·부적 거울, 서아가 사라졌다 반대편에서 나타남) → 불 꺼짐·슥슥·단장 접근 → 추격 → 모니터실('관객 312 / 접속자 1', 맨 앞줄에 고개 숙인 '나') → EXIT 앞에서 서아의 얼굴이 소용돌이, 단장 대사를 서아 목소리로 → 내 방(입장 4,119회째, 천장 이음매) → 엔딩 A(다시 눕기) / B(창문 열기·밤 도시 비행)
- 기술 메모: 엔진은 `N` 노드 객체(scene/enter/lines/choices/timer/next/end), 줄마다 `fx`·`wait`(자동 진행, 건너뛰기 불가)·`do` 훅. 장면은 `SCENES` 캔버스 함수.
- **이미지가 v0에 안 들어간 이유:** Cowork 클라우드 작업 공간은 허용된 도메인으로만 외부 접속이 된다. 힉스필드 결과 CDN이 허용 목록에 없어 프록시가 다운로드를 거부(403)했고, 아티팩트는 외부 이미지를 직접 불러올 수 없어 코드 그림으로 대체했다. Claude Code(로컬)에서는 이 제한이 없다.

## 5. v0 플레이테스트 (사용자 후기, 11/21)

**만들기 전 가설:** 괴물의 흔적을 보고 의아해하며 언제 나타날지 모르는 긴장감(백룸의 미묘한 단서처럼) → 직접 모습을 드러내고 추격할 때 → 친구가 붕괴될 때.

**해 본 결과 (사용자 말 요약):**

- ✅ 친숙한 대상으로 커플(친구)을 고른 건 괜찮았다.
- ✅ 음악이 조금씩 이상해지면서 '엥?' 하고, **관객들이 비정상적으로 똑같이 행동하는 게 소름**. 시각 이미지가 같이 있으면 확실히 더 무서울 듯.
- ✅ 마지막에 서아가 '신사 숙녀 여러분~' 하며 **단장 목소리를 내는 건 무서웠다.**
- ✅ 천막 붕괴 뒤에도 **관객들이 그대로 앉아 웃고 있는 건** '예측'을 깨뜨려 묘한 감정을 줬다.
- ⚠️ 단장이 말할 때 지지직거리는 소리가 거슬림. → (AI 메모) 의도한 음성 효과가 아니다. 단장 멘트마다 붙인 **박수 효과음을 노이즈로 합성해서** 지지직처럼 들린 것. 음성이나 다른 효과음으로 바꿀 것.
- ⚠️ 서아의 이상한 포인트: "손 차갑다, 너"는 뜬금없음. 뭔가 아는 듯한 멘트로 의아함을 주려던 의도는 보임. 사라졌다 이상한 곳에서 나타나는 건 나쁘지 않음.
- ⚠️ **지금 서사로는 서아가 무섭기보다 사연 있어 보임**(트루먼 쇼에서 주인공을 돕는 서브 여주처럼). 매력은 있지만 공포는 안 생김. 단서를 너무 많이 줘서일 수도. (대안으로 공포 비중을 줄이고 가상/실제 경계·철학적 좀비를 고찰하는 게임·체험도 열어 둠)
- ⚠️ 서커스에서 다른 곳으로 가는 컨셉은 좋은데, **이미지가 너무 갑자기 매트릭스 세계라 '잉?'**. → 붕괴 뒤 **점차** 가상현실로 넘어가거나 이상한 트릭을 주는 방향은?
- 가설 대비: 흔적·추격은 후기에서 언급 없음. 예상 밖으로 **음악 이상 + 관객 동기화**가 소름 포인트였고, 친구 붕괴는 '단장 목소리'에서 통함.

### 열린 질문 (사용자가 정할 것 — grill me 재료)

1. 서아를 **공포의 대상**으로 갈까, **사연 있는 존재(트루먼 쇼형)**로 갈까, 아니면 둘을 잇는 무엇(처음엔 사연, 끝에 공포)?
2. 서아에 대한 단서를 몇 개까지 줄까? 어느 순간에 처음 '어?'를 줄까?
3. 현실 → 가상 전환을 몇 단계로 할까? 각 단계에서 무엇이 먼저 깨질까(소리 → 사람 → 공간?)
4. 공포 중심으로 갈까, 철학(가상/실제, 철학적 좀비) 중심으로 무게를 옮길까? 비율은?
5. 단장의 정체와 서아의 관계를 플레이어가 끝까지 알아야 할까, 모호하게 남길까?
6. 엔딩 A/B 중 무엇이 남길 느낌에 맞나?

## 7. 문헌에서 이미 확인된 것 (11/21 팩트체크, 설계에 쓸 것만)

- **"상대가 나에게 반응한다"는 감각**이 공포를 키운다는 간접 근거(VR 좀비 게임, Lin 2017). 형식 자체(메신저냐 산문이냐)의 효과는 검증된 적 없음. → 동료가 플레이어에게 반응하는 설계가 핵심.
- **기다림(예기)은 그 자체로 괴롭고, 불확실할수록 커진다.** 그러나 실시간으로 재면 공포의 정점은 대개 마주치는 순간(Hudson 외 2020). → 긴 서스펜스 + 드문 피크 구조와 맞음.
- **불확실성은 실제로 당한 것과 별도로 스트레스를 더한다**(de Berker 외 2016). → 언제 올지 모르는 위협(랜덤 딜레이)이 유효.
- 섬뜩함은 '위협인지 아닌지 모호할 때'의 경계(McAndrew & Koehnke 2016, 광대 연구). → 단장·동료 모두 '의도를 읽을 수 없음'이 핵심.
