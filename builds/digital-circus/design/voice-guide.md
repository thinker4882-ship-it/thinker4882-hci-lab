# 말투 가이드 — 주인공·서아 (11/28)

> 대사 방식(11/28 정웅 결정): 정웅 말투 견본 → Claude가 그 말투로 씀 → 다른 모델이 다듬음. 반전은 계속 비밀.
> 만든 방법: Claude가 **게임 밖 연습 장면**으로 견본을 쓰고, 정웅이 줄마다 고친 걸 비교해 뽑음. 게임 대사·반전은 이 파일에 없음.
> 정웅: "이 말투가 진리는 아님." 여러 참고 중 하나로 쓰고, 실제 공포 장면에서 다시 고친다.

## 인물
- 둘 다 20대 후반, 연인. **서아는 주인공보다 연상** (11/28 확정, "누나가 쏠게!").
- 서아: 걱정하고 챙기면서도 장난스러움. 걱정할 때 말끝을 흐림.
- 주인공: 투덜거릴 때 남 탓보다 자기 후회. 과장·속어를 씀.

## 말투 가이드 (16항목)
### 일상 장면 (v1에서)
1. 첫마디는 반응 소리: 엥?? / 하... / ㅋㅋㅋ / 아 귀찮은데... (Claude는 바로 내용부터 말함)
2. 말끝을 흐림: ... .... .. — 특히 서아가 걱정할 때 ("어떡하지...", "~가야하나..")
3. 감정 표시 글자 ㅠㅠ ㅋㅋㅋ ~ ㄹㅇ (메신저 말투) — **일상 장면에서만** (11/28 정웅 결정)
4. 단정 대신 완충어: 그런 거 같아 / 그냥 / ~겠지 / 지금 가볼게
5. 투덜거림은 자기 후회: "좀만 더 빨리 올 걸" (Claude: "오늘 왜 이러냐")
6. 반문은 "~는데?": "제일 맛있는데?"
7. 과장·속어: "이 정도면 ㄹㅇ 싸이코 아니냐??"
8. 구체적인 때: "다섯 시에" → "퇴근 직전에"
9. Claude 문장은 짧고 딱 끊겨 점잖고 무뚝뚝함 → 조금 더 길고 말랑하게 (정웅 총평: "상투적. 너무 점잖다. 리얼함·핍진성이 덜하다.")
### 긴장 장면 (v2에서)
10. 서아는 연상으로 챙기는 쪽 (위 '인물')
11. 긴장할 때 첫마디는 한숨 "하..."
12. 원인을 묻기보다 지금 느끼는 걸 말함: "불 왜 꺼져" → "아무것도 안 보이는데?"
13. 혼잣말로 과정을 늘어놓지 않고 상대에게 제안·질문: "비상벨 어딨지... 이거 맞나?" → "비상벨 눌러볼까??"
14. 작가 같은 세부 묘사 대신 흔한 말: "한 칸. 왔다 갔다 해" → "데이터도 먹통이네"
15. 다툼·지친 장면은 짧게 끊는 말이 맞음 (v2에서 그대로 통과). '점잖다' 문제는 일상 장면에서 큼
16. "??"는 긴장 장면에서도 씀 (ㅋㅋ ㅠㅠ ~ 만 일상 전용)

## 금지 패턴 (v3 첫 판 후기 원인 2번에서)
- 설계도의 의도 문장을 그대로 대사로 쓰기
- 괄호 속마음으로 감정·의미 풀기
- 캐릭터가 게임 규칙을 읽어 주기
- 연결하려고 넣은 설명 대사
- 문어체 감정 고백
