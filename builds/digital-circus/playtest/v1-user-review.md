# v1 사용자 플레이 후기 (2026-11-22)

정웅이 v1(`v1/circus-v1.html`)을 직접 해 본 뒤 남긴 후기를 주제별로 정리. 표현은 최대한 원문 그대로.

## 1. 큰 판정
- 이론만으로 만든 서사는 아직 어설프다. "상투적이고 유치하고 노잼이고 어설프다."
- 원인 추정: 모든 사건을 말로 설명해서. 서사와 게임플레이 사이의 매력·정합성·연결이 약함.
- 더 기괴했으면.
- 흐름이 애매하니 결말도 약해짐. ("현실도 가상현실" 의도 자체는 OK)
- 방향 후보(사용자): 서사를 더 소름 돋게 갈아엎기 / 시각·게임 구성으로 더 구현하기 / 검증된 서사 차용.

## 2. 세계 톤 — 원래 원했던 그림과 어긋남
- 지금은 서커스 쪽으로 너무 치우침.
- 원래 원한 그림: **친숙하지만 어딘가 이질적인 가상세계, 고독하고 어딘가 공허한 세계.**
- 게임 말고 영상이 더 맞을까? 하는 의문도 있음.

## 3. 형식
- 탐색·미션이 없어서 이상함. 선택지 게임이면 미연시식 서사, 쯔꾸르(2D 탐색 어드벤처) 참조. 미션을 줄 거면 3D 게임 참조.
- 사람·서아와 대화할 때 캐릭터 이미지가 나왔으면(미연시처럼).
- 어디로 가고 있다는 감각이 없음. 이동을 말로 설명해서 "뭐 어쩌라고?"가 됨.

## 4. 무서웠던 것 / 안 무서웠던 것
**먹힌 것**
- v0에서 옆자리 남자가 이상해지는 묘사는 꽤 섬뜩했음.
- 단장 추격: 그나마 긴장감. 효과음 영향도 있었음.
- 서아가 오류 난다는 컨셉 자체.

**안 먹힌 것 (장면은 사용자가 말한 대사 기준)**
- "저번에 멀미해서 나한테 기댔잖아" — 어설프고 어색.
- 단장의 반복 대사: 그 자체는 별로 이상하지 않음. 두 번째부터 "방금 했던 말이다" 하고 갑자기 심각해지는 게 오히려 이상.
- 관객 동기화를 문장으로 설명("같은 높이, 같은 길이로", "모든 고개가 같은 속도로") — 별로. → **설명 말고 행동으로 보여 주고, 사람 대사만.** 계속 이상하게 웃는다거나, 부자연스러운 행동을 점차 알아차리는 게 무서울 것.
- "나가자 지금" — 아직 충분히 이상하지 않은데 탈출로 넘어감. 무너지거나 문제가 생긴 뒤 빠져나가는 게 자연스러움.
- 불상·부적 컨셉: 나쁘지 않은데 떠먹이는 느낌. 세계관 이해가 덜 돼서? 더 탐색하게 해야?
- "웃지 마. 따라 웃으면 거기 앉게 돼" — 강조하려는 게 보이지만 섬뜩하지 않고 인위적.
- 무대 반대쪽으로 걸어 나가기, 초록 출입구 표시 사라짐 — 이상하게 느껴지지 않음.
- 서아가 가이드처럼 계속 리드 — 티 나고 어색. 게임 형식 문제일 수도.
- 사자 그림 — 의도는 알겠으나 긴장·직접 위협이 안 느껴짐.
  - 참고로 무서웠던 다른 게임 경험: 유리 너머 웃는 마네킹 → 반대편 물건 줍고 오니 사라짐 / 관 속 시체 → 돌아오니 효과음과 함께 사라짐. (**공간을 오가는 사이에 바뀌는 것**)
- 단장이 어떻게 다가오는지 묘사가 중요.
- 서아 오류: 회전목마 멘트가 별로라 의도가 안 삶. 적절한 멘트를 반복하고, 조금씩 이상해지고, 관객처럼 웃고, 단장 말을 이상한 표정으로 따라 하는 걸 **시각적으로** 보여 주면 섬뜩할 것.
- 쪽지 떨어지기, "도망친다" 선택지 3개 — 딱히.
- 입장 4,120회째 컨셉 — 효과적인지 의문.

## 5. 한계 (사용자 자기 진단)
- 게임플레이·공포물 경험 부족. 공포 게임·콘텐츠를 많이 접해 본 적이 없음 → 인디 게임이라도 더 해 볼 필요.
- 비전이 뚜렷하지 않았나? 상상·이론과 실제 구현 사이의 간극.
- 더 명확한 요소 지시가 필요했나?

## 6. AI에 대한 질문 (노션 아카이브용 — 나중에 정리해서 넣기)
- AI는 재미있는 게임·스토리를 만들 수 없나? 진짜 재밌는 서사·기획은 인간이 해야 하나? AI는 훌륭한 구현 도구에 불과한가?
- AI가 게임을 실제로 플레이하고 무엇이 좋았는지 판단(취향·가치판단)할 수 있나? 텍스트로 읽는 것과 다른가? 이게 AI의 한계 지점인가?
- 그럼 결국 여러 서사·게임을 겪은, 고유한 취향을 가진 인간이 필요한가?
- 퀄리아를 생생하게 체험하는 시뮬레이션을 만들 수 있나? VR?
