# v2 첫 장면 '밤 버스' 사용자 후기 (2026-11-22)

- 판정: v1보다 확실히 나아짐. 전체 구성이 훨씬 좋아짐. "이런 느낌으로 서사 더 덧붙여서 완성도 있게 만들면 괜찮을 듯."
- 제일 놀란 순간: 고개 돌렸을 때 뒤에 갑자기 사람이 나타남. 세 번쯤 죽음.
- 버스의 음산한 분위기 자체가 무서움.
- 미연시 → 3D 형식 전환: 나쁘지 않았음.
- 아쉬운 점: 그래픽(서아 얼굴, 주변 배경 → 힉스필드 활용 제안), 3D 조작감. 서사는 아직 있다고 하기 어려움(초안이라).

## 가설과 비교
| 가설 (blueprint-v2 4번) | 이번 초안에서 |
|---|---|
| 현실이 어그러질 때 | 분위기(음산한 버스)는 먹힘. 장면 하나라 '어그러짐'의 단계는 아직 시험 안 됨 |
| 쫓기다 어디 있는지 모름 | **맞음.** 뒤돌아보니 사람이 있던 순간이 최고점. 길 잃음은 아직 없음(버스는 일자 통로) |
| 서아의 배신 | 이번 장면 범위 밖 |
