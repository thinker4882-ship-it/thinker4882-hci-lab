# v2 본편 2단계 사용자 후기 (2026-11-22)

- 판정: 전체적으로 구성력이 좋아짐.
- 좋았던 것: 갑자기 리미널 스페이스로 들어온 것. 서아가 혼자 들어갔다 나오는 것(크게 이상하지 않으면서 나중에 씨앗이 될 만함).
- 정전 규칙: 계속 죽어서 버그인가 했다가, 멈췄더니 안 죽어서 "아 이렇게 하는 거구나". 서아의 "천천히 가자"가 힌트였다면 괜찮았을 것 같다고 함(의도한 힌트는 아니었음).
- 아쉬운 것
  - 조작법이 아직 낯섦. 처음 조작법 문구가 너무 흐려서 안 보임.
  - 뭐가 뭔지 구분이 안 됨: 편의점인 줄 몰랐고, 마네킹·안내도를 못 알아봄. (그림은 5단계에서 개선 예정)
  - 복도 왼쪽 물체 두 개(자판기, 포스터)의 용도를 모름. 눌러도 반응 없음.
- 질문: 다들 잠깐 멈췄다가 서아가 "……가자" 하는 것도 의도? → 의도한 연출.

## 고친 것
- 조작법 안내: 진하고 큰 글씨, 배경 상자, 더 오래 표시.
- 장소·물건 이름표: 편의점·옷가게·관리실·안내도·비상구·정문, 복도의 자판기·안내문.
- 복도 자판기·안내문·벤치 살펴보기. 안내문은 실제 안전 안내문처럼 정전 규칙을 슬쩍 알려 줌(바퀴가 지나면 서커스 포스터로 바뀜).
