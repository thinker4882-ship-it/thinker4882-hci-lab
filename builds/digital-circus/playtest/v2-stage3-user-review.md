# v2 본편 3단계 사용자 후기 (2026-11-22)

## 1차 (Version 8)
- 단장의 "자리에 앉아 주세요"를 지시로 읽고 앉으려다 계속 잡혀 죽음. 점프도 안 됨.
- 위협이라고 확정되기 전에 죽는 게 이상함. 서커스 전 복도에서 단장에게 죽는 것도 이상함.
- → Version 9에서 고침: 복도에서 잡는 존재 교체, 추격 전 위협 연출, 목표(비상구) 명시, 객석에 오르려 하면 붙잡힘.

## 2차 (Version 9)
- 초반 위협이 별로. 서커스를 먼저 좀 봐야 하지 않나.
- 흐름 제안: 서커스라는 환경에 익숙해짐 → 이변이 생기고 이상함을 느낌 → 위협이 자연스럽게 드러남 → 도망.
- 단장이 따라오는 속도가 너무 빠름.
- PC 조작이 아직 어색함. 단장을 보면서 뒷걸음치는 방식이어야 겨우 가능한 느낌.
- 마우스 드래그만으로 화면이 움직였으면 함.
- 판정: 파트 3 서사를 전체적으로 다시 손봐야 함.

## 3차 (Version 10, 서사 다시 짠 판)
- 공연을 볼 때 자리에 앉아 있지 않았음(발밑이 객석이 아니라 무대 바닥).
- 위협을 느끼게 하는 대사·상황이 와닿지 않음.
- 도망이 조잡함: 여러 공간을 거치는 게 아니라 무대 안에서만 도망쳐서 기묘하고 무섭지 않음.
- 기대했던 것: 파피 플레이타임에서 쫓길 때, 에일리언이 쫓아올 때 같은 서스펜스와 박진감.
- 질문: 그래픽이 조잡해서 그런가? 전체적으로 손봐야 하나?

## 4차 (Version 11, 객석 관람 + 복도 추격)
- 판정: 초안으로는 괜찮지만 최종 결과물로는 아직 미흡.
- 좋았던 것: 단장이 갑자기 앞으로 와서 "일어나시면 안 됩니다" 하는 순간. 추격전은 이전보다 훨씬 나아짐.
- 아쉬운 것
  - "이거 아까 그거 아니야?"(같은 순서 반복)가 그리 이상하게 느껴지지 않음. 행동이 기괴해지는 쪽이 나을 듯.
  - 광대가 넘어지는 게 무슨 의미인지 모르겠음.
  - 추격이 무섭기보다 서아를 따라가기만 하는 느낌. 자율성이 더 있어야 하나?
  - 천막으로 돌아온 뒤 "왜 다시 여기지?" 하고 생각할 틈이 없음. 서아가 바로 말해서 갑작스럽고, 반전이 크게 느껴지지 않음.
