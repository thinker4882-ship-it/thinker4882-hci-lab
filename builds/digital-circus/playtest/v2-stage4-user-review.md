# v2 본편 4단계 사용자 후기 (2026-11-23)

## 1차 (Version 13, 계단 5 틈 + 엔딩)
- 3단계: 옷 뒤에 숨기가 처음에 인식이 안 됨(판정 오류). 숨는 연출도 조잡함. → 나중에 개선.
- 4단계 틈: 갑자기 게임 오류가 떠서 나조차 속음. "엥 게임 오류까지 나네.. 그냥 나갈까?" 생각하던 중 버스로 돌아옴.
- 다시 시작된 버스에서 서아가 "하지 마. 진짜 그럴 것 같잖아." 하기 전에 내 대답을 받는 게 없어서 어색함.
- 버스에서 마구 오류가 날 때 꽤 섬뜩함.
- 결말: 최악은 아니지만 사알짝 아쉬움. 더 개선할 수 있겠다는 느낌. "다음은 수정교 정류장", "그러게"가 무슨 의미인지 모르겠음.

## 가설과 비교 (design/stage4-hypothesis.md)
| 가설 | 결과 |
|---|---|
| 1. 예상을 깨는 오류창·화면 깨짐이 제일 무서울 것 | 맞음. 만든 사람인데도 진짜 오류로 속음. 버스 오류 장면도 섬뜩. |
| 2. 완전히 안심 → 적당한 섬뜩함 → 오픈엔딩 | 안심까지는 갔지만 섬뜩함이 전달 안 됨. 단서의 의미를 못 읽음. |
| 3. 내가 무섭거나 잘 만들었다고 판단해야 성공 | 틈: 성공. 엔딩: 아직. |

## 개선 목록 (다음 판 후보)
1. 엔딩의 마지막 섬뜩함이 읽히게 다시 짜기 (가장 큼).
2. 다시 시작된 버스에서 첫 대답 선택지가 안 보인 문제 고치기 (버그로 보임, 아래 메모).
3. (나중) 3단계 숨기: 판정 범위와 연출.

## 메모
- 2번 원인 추정: 코드에는 선택지가 있음. 앞 대사를 넘기려고 누른 자리에 선택지 버튼이 곧바로 생기면, 같은 터치가 버튼 클릭으로 들어가는 경우가 있음(특히 터치 화면). 선택지가 뜬 직후 잠깐은 누름을 무시하게 하면 막힘.
