# v3 첫 판 정웅 후기 (2026-11-27)

> 한 줄 요약: "틀은 얼추 나왔는데 재미가 없고, 대사가 어색하고, 왜 그걸 해야 하는지 모르겠고, 무섭지 않다."

## 장별 후기 (정웅 말 거의 그대로)

### 0. 일상 (도입)
- 원래 버스에서 시작하던 도입부가 자연스러웠는데 버린 건지 궁금함. 다만 버스에서 컴퓨터로 이어지는 흐름은 만들기 어려워 보임.
- 요즘 집에 왜 구식 컴퓨터가 있지? 정웅이 직접 낸 후보: 본가에서 가져옴 / 엄마가 버리라고 해서 잠깐 들고 옴 / 설명 없이 감 / 코드도 안 꽂았는데 저절로 켜짐.
- 대사가 미묘하게 어색함. 예: "뭐야 스팸이야? 꺼". 정웅이 직접 쓴 예시: "엥? 저거 컴퓨터에 불 들어온다", "뭐지? 코드 뽑혀 있는데".

### 1. 채팅창
- "나는 여기서 9,131일 동안 아무도 안 만났어." → '못 만났어'나 '혼자 있었어'가 맞음.
- [미안, 우린 먼저 가야 해]를 골라도 [초기화]와 대사가 똑같음. 고른 쪽에 따라 과정이 달라야 함. 정웅 예: "역시 너희도 그럴 줄 알았어." → 화면이 깜빡거림 → "죄송합니다. 오류가 발생했습니다." → 정상 안내로 바뀜.
- 초기화가 '자의식을 지워 주는 것'이 맞는지 다시 볼 것.
- 자의식이 있어서 여기 머무는 게 고통스럽다는 게 아직 체감도 안 되고 이입도 안 됨.
- 탄막은 나쁘지 않음. 다만 서사를 더 붙이거나 게임성을 넣고 싶음. 언더테일은 이걸 어떻게 하는지 궁금함.

### 2. 꿈의 들판
- 3D로 만들면 좋을 것 같음. 정웅이 생각한 이미지를 보내 줄 예정.
- '꿈의 들판'이 실감 나지 않음. 가상현실의 좋은 것만 모은 꿈의 동산이어야 함: 다들 굉장히 행복하고 환상만 가득한데, 어딘가 아이러니가 있는 세상.
- 지금은 한 사람을 찍어야 다음 사람으로 넘어감. 이 방식밖에 없는지 궁금함.
- 처음 하는 사람은 '말이 어긋나는 사람을 찍어서 증거를 모아야 한다'는 걸 모를 것. 그리고 게임성이랄 게 없음. **"무엇보다 별로 재미가 없네."**
- 서아의 "말 잘 들어. 거짓말하는 데서 사진을 내밀어."가 정말 별로임. 왜 갑자기 이 말을 하는지 모르겠음. 차라리 미니게임처럼 규칙을 제대로 알려 주는 게 나을 수 있음: 이야기를 따라가다 본 게임에 들어가면 규칙 설명 → 될 때까지 시도.
- 정원사·빵집 주인·안내원의 말이 서로 맞는지 다시 볼 것.
- 지하에 사람들이 다 묶여 있는 건 섬뜩함. 그런데 들판의 환상적인 모습이 덜 드러나서 "얘네는 뭐지?" 싶음.

### 3. 서커스
- 서커스로 넘어가는 게 이상함. 갑자기 왜 보러 가지? 다음 갈 곳이 거기밖에 없게 하는 장치나, 누가 찾아 달라고 하는 식의 이유가 필요함.
- 추격은 v2를 그대로 다시 씀. 본판에서는 맵을 리미널 스페이스로 늘리고 규모와 게임성도 키우는 거 맞지?
- 오르골은 "저거 내 거야" 하는 게 이해됐는데, 키링은 무슨 상관인지 모르겠음. 키링이 오르골인 건가?
- "채팅창에 끌려갈 때 없어졌었는데"는 전혀 필요 없는 대사.
- 오르골이 왜 소리가 나야 하는지, 부품을 왜 찾아야 하는지 이어지는 이유가 부족함.
- 거울에 손톱으로 긁은 자국은 뭔지 모르겠음.
- 서아가 "두고 가지 마" 하면서 웃는 게 짜침. 뒤에서 갑자기 단장이 나타나는 것도 별로. **전혀 무섭지 않음.**
- 단장의 "나도 매일 그걸 봐"가 무슨 말인지 모르겠음.
- 그렇게 쫓아오던 단장이 "우린 둘 다 나가요" 한마디에 그냥 보내 주는 게 이해 안 됨. 오히려 "나를 대신할 사람이 필요하다고!" 하며 쫓아오거나 뭔가 해야 하지 않나.

### 4·5. 귀환·엔딩
- "(우린 저렇게 안 돼.)" 같은 속마음을 계속 넣는 게 짜침.
- "이대로, 이 진짜 삶을 온몸으로 느끼며 살아가고 싶다."는 사람이 하는 말이 아님. 정웅 예: "그냥 모든 게 이대로였으면 좋겠다. 사랑하는 가족과 충만한 삶을 즐기면서.."
- 마지막 장면이 의도와 다름. 의도: 둘이 이야기하며 어딘가로 자연스럽게 걸어 나가고, 아무도 의심하지 않는 순간 평범한 물건 하나가 이상한 전자 매트릭스 같은 오류를 냄. 도트라서 그 오류도 별로 이상해 보이지 않음. **두 사람이 고개를 돌리는 건 전혀 의도가 아님. 두 사람은 모르고 그냥 가야 함.**

### 전체
- 낙원 서비스의 디자인과 조형은 나중에 더 사실적이고 풍성하게 바꾸는 거지? 지금은 저충실도(로우 피델리티)로 구조만 보는 판.
- 이곳저곳에 AI slop 특유의 어색함이 묻어남.
- "AI랑 함께 서사가 탄탄한 게임은 만들 수 없는 건가? 인스타에 소개된 게임들도 서사보다는 단일한 게임이었으니까… 서사 말고 그래픽 좋은 게임이나 만드는 게 최선인가."

## 가설과 비교
| 가설 (만들기 전) | 결과 |
|---|---|
| 1. 제일 무서울 곳은 서커스 (쫓기면서 긴박하게 미션을 해야 해서) | **안 맞음.** "전혀 무섭지 않음." 추격은 v2를 그대로 썼고, 가짜 탈출은 웃음 → 단장이 나타나는 상투적인 깜짝 놀래기로 끝남. 쫓기는 이유(단장에게 대신할 사람이 필요함)가 추격 중에는 안 보였고, 끝에서 단장이 그냥 보내 줘서 위협도 사라짐. |
| 2. 엔딩 뒤 "아직도 가상현실인가? 탈출 못 한 건가?" | **안 일어남.** 연출이 의도와 반대였음(두 사람이 알아채고 돌아봄 = 설계도에 없던 연출). 도트라서 지지직이 이상해 보이지도 않음. |

## 원인 진단 (Claude)
후기를 원인별로 묶으면 다섯 갈래야. 다섯 개가 서로 다른 문제라서 고치는 방법도 다 달라.

1. **왜 하는지가 끊김.** 플레이어가 그 순간 이유를 모르는 행동이 많았어: 구식 컴퓨터, 서커스로 가기, 부품 찾기, 오르골이 울려야 나가는 이유, 키링 = 오르골, 거울 자국, 단장이 보내 주는 이유.
   - 원인: 비밀 개요가 '장면 목록'이었지 '왜 사슬'이 아니었어. 25분으로 줄이면서 이유를 놓는 장면부터 잘려 나갔어.
2. **대사가 AI 말투.** 패턴이 넷이야.
   - (a) 설계도에 적은 '의도 문장'을 거의 그대로 대사로 넣음. 예: "또 두고 가지 말란 말이야", "이 진짜 삶을 온몸으로…". 설계도 문장은 뜻을 적은 거지 사람이 하는 말이 아니야.
   - (b) 감정과 의미를 말로 풀어 버림. 예: 괄호 속마음 "(우린 저렇게 안 돼.)".
   - (c) 캐릭터가 게임 규칙을 대신 읽어 줌. 예: "거짓말하는 데서 사진을 내밀어".
   - (d) 연결하려고 넣은 쓸데없는 설명. 예: "채팅창에 끌려갈 때 없어졌었는데".
3. **규칙 전달과 게임성.** 들판에서 '무엇을 하는 게임인지'를 대사 한 줄로만 알려 줬어. 그런데 할 일은 순서가 정해진 클릭이라 판단할 거리가 없었어. 탄막은 손맛은 있었지만 이야기와 따로 놀았어.
4. **공포가 안 생김.** 같은 추격을 다시 썼고(새로움 없음), 깜짝 놀래기는 상투적이었어. 위협의 이유도 흐렸어(1번과 이어짐).
5. **연출이 의도와 어긋남.**
   - 엔딩에서 고개를 돌림. 설계도엔 "둘이 손잡고 걸어감"이라고 돼 있었어. 내 실수야.
   - 채팅창의 두 선택이 같은 대사로 이어짐.
   - 들판의 환상을 충분히 보여 주기 전에 지하를 보여 줌.

※ 충실도(2D·도트·조형)는 원래 이번 판에서 구조만 보려고 낮게 둔 거야. 본판에서 들판 3D, 서커스 리미널 확장, 낙원 디자인을 사실적이고 풍성하게 바꾸는 게 원래 계획이야(`v3/README.md` 표).

| 원인 | 고칠 것 |
|---|---|
| 1. 왜 사슬 | **'왜 표'** 만들기: 플레이어 행동 하나마다 "그 순간 플레이어가 아는 이유"를 한 칸씩 적고, 빈칸이면 그 장면은 만들지 않음. 서커스로 가는 강제 장치, 부품·오르골의 이유, 단장이 끝까지 막는 이유(대신할 사람)를 여기서 다시 짬 |

| 3. 들판 게임성 | 규칙을 대사가 아니라 첫 판에서 몸으로 배우게 함(튜토리얼 판). 순서 고정 대신 자유 순서와 여러 단서 중 고르기. 3D로 꿈의 동산 실감 내기(정웅 이미지 받은 뒤) |
| 3. 채팅창 | 탄막이 곧 이야기가 되게 함(언더테일식 참고, 아래). 두 선택이 다른 과정을 거치게 함(정웅 안: 원망 → 깜빡임 → 오류 → 정상 안내) |
| 4. 공포 | 서커스 본판(리미널 맵, 길찾기 단장)에서 새로 짬. 깜짝 놀래기 대신 이유 있는 위협 |
| 5. 엔딩 | 둘은 끝까지 모름. 걸어가는 뒷모습 + 물건 하나만 오류. 오류는 도트가 아닌 질감으로 해야 '이상함'이 보임 |
| 작은 것 | "아무도 안 만났어" → "아무도 못 만났어"/"혼자 있었어". 증언 매칭 다시 보기 |

## 정할 것 (정웅 결정 대기)
1. **대사를 누가 어떻게 쓸지.** 스포일러 규칙(정웅은 대사를 미리 안 봄)과 부딪히는 지점이라 정웅이 정해야 함.
2. **다음 판의 방향** (전체를 다시 짤지 / 한 장만 끝까지 다듬을지 / 실감·그래픽부터 올릴지).
3. 도입: 버스를 살릴지, 컴퓨터가 왜 집에 있는지 (정웅 후보 4개).
4. 초기화 = 자의식 지우기가 맞는지.
