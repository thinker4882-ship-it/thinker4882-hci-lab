# 단계별 프롬프트 (Claude Code에 붙여 넣기)

## 1. 첫 세션 — grill me로 설계도 파기

    CLAUDE.md와 HANDOFF.md를 먼저 끝까지 읽고, HANDOFF.md 6번의 노션 페이지 중
    '🧭 이번 주 기획'(맨 아래 11/21 기획안 초안 포함)과 '공포 연구 노트'를 Notion MCP로 읽어 줘.

    그다음 순서:
    1. HANDOFF.md 부록 A대로 이미지 3장을 assets/에 내려받아.
    2. 읽은 내용을 5줄 이내로 요약해서, 네가 맥락을 제대로 잡았는지 나한테 확인받아.
    3. grill me 스킬로 내 설계도를 파고들어 줘. HANDOFF.md 5번 '열린 질문'부터.
       라운드마다 서로 의존하지 않는 질문을 묶어서 번호를 붙여 물어. 내 답에서 다음 라운드를 뽑아.
       추천 답은 붙이지 말고, 질문마다 v0 후기·문헌 근거 한 줄만. 내가 "네 생각은?" 하면 그때만 의견.
       추상적인 질문엔 구체적인 예를 붙여. 대사나 반전 아이디어는 먼저 제안하지 마.
       (같이 돌리기: v0를 3번 '첫 플레이어' 에이전트로 점검해서 서아·단서 질문의 근거로 써.)
    4. 내가 "그만"이라고 하면, 내가 한 말만으로 design/blueprint-v1.md 초안을 만들어 보여 줘.
       (네 아이디어를 섞지 말고, 빈칸은 빈칸으로 남겨.)

    리서치나 v1 빌드는 blueprint-v1이 확정된 다음에 할 거야.

## 2. 설계도 확정 후 — 다중 에이전트 리서치

    design/blueprint-v1.md를 기준으로 리서치를 병렬로 돌려 줘. 서브에이전트 3개:

    A. 사례 — 내 설계도의 장치를 실제로 구현한 작품 3~4개의 '구조'만.
       (믿던 동료가 낯설어지는 장치, 현실이 단계적으로 무너지는 디지털 호러,
        철학적 좀비·시뮬레이션을 다룬 게임·서사)
       작품마다: 기저선을 어떻게 까나 / 무엇이 어긋나나 / 플레이어가 무엇을 하나 / 내 설계와 닿는 지점.
       줄거리·결말 스포일러 금지. 공포 연구 노트에 이미 있는 작품(P.T., 8번 출구, Local 58, 백룸,
       TADC, Petscop, DDLC)은 빼.
    B. 원리 — 철학적 좀비(SEP 수준), 시뮬레이션 가설, 섬뜩함·언캐니 연구.
       합의 / 논쟁 / 모름을 나눠서. 출처 확인 수준 표기.
    C. 기법 — 브라우저에서 PS1풍 3D(저해상도 렌더 타깃, 버텍스 스내핑, 아핀 텍스처, 디더링),
       점진적 글리치 연출, WebAudio로 음악이 서서히 틀어지는 효과. 실제로 동작하는 최소 예제 위주.

    규칙은 CLAUDE.md '리서치 규칙'. 결과는 research/ 폴더에 A·B·C 파일로 저장하고,
    나한테는 '내 설계에 바로 쓸 것' 3줄씩만 요약해 줘. 고르는 건 내가 할게.

## 3. 빌드 후 — '결말을 모르는 첫 플레이어' 에이전트 점검

목적: 만든 사람은 결말을 알아서 서사를 제대로 테스트할 수 없다(설계자 효과). 설계 문서를 읽지 않은 에이전트에게 빌드만 주고 플레이 로그를 받는다. **에이전트가 "무섭다"고 해도 근거로 쓰지 않는다.** 이해 가능성·단서 맞물림·속도 점검용이다.

    vN/ 빌드를 '첫 플레이어' 서브에이전트로 점검해 줘.
    - 서브에이전트에게는 빌드 파일 경로만 주고, CLAUDE.md·HANDOFF.md·design/·script/·research/는
      절대 읽지 말라고 해. (Playwright로 실제로 클릭하며 진행하게 해도 좋아.)
    - 선택지는 매번 '처음 하는 사람이 고를 법한 것'으로 고르고, 다른 엔딩도 한 번 더 해 보게 해.
    - 장면마다 기록: 지금 무슨 일이 일어났다고 이해했나 / 다음에 무슨 일이 일어날 것 같나(예측) /
      헷갈린 점 / 지루하거나 늘어진 곳 / 너무 일찍 눈치챈 것(단서가 과한 곳).
    - 끝나고: 이 이야기를 세 줄로 요약하면? 동료는 어떤 존재라고 생각했나? 언제부터 그렇게 생각했나?

    나한테 줄 때는 반전 내용을 직접 쓰지 말고 장면 번호로만 말해 줘.
    ('7장에서 동료의 정체를 너무 일찍 눈치챔' 정도.) 수정 제안은 내가 고른 다음에 할게.

사람 플레이테스트와 같이 볼 것: 내가 고른 '소름 돋은 순간'(엔딩 화면 기록 복사) vs 만들기 전 가설 / 에이전트가 '눈치챈 시점' vs 내가 의도한 시점.
