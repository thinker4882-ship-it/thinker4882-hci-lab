## 0장 · 일상 (11/28~)
**정웅 결정 (11/28)**

## 0장 셋째 판 (11/29, 둘째 판 후기 반영)
- 둘째 판 후기: 3D 빨래방은 "너무 좋다". 드럼 안 도트가 조잡함, 2D 서아가 따라다녀 어색함, 게시판도 그림으로, '자동문' 글자 빼기, 자판기 재방문 때 음료를 또 사게 하는 것 별로, 문을 밀 때 갑자기 바깥 풍경이 나오는 것보다 창밖을 먼저 보여 주고 나중에 바뀐 모습으로.
- 고친 것 → 맡은 곳: 드럼 안 = 힉스필드 사진을 둥근 유리 자리에 겹쳐 텍스처만 돌림(`W.myDrum`, `W.dryerSpin`, `loop`의 `TEX.drum*.rotation`) / 서아 = 의자에 앉아 있고 따라오지 않음(`placeSeoa('bench')`) / 게시판 사진(`TEX.board`) / 앞문 글자 삭제 / 창 누르기 `window` 장면, 의자에서 기다리며 창밖을 봐 둠(`EV.look_out`·`EV.look_back`) → 앞문이 막힌 뒤 창으로 고개를 돌려 바뀐 거리(`EV.outside_2`, `turnTo`) / WASD·화살표 걷기(`stepKeys`) / 자판기는 세제만 사면 끝(대본)
