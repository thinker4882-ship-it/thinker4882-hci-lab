## 문제의식
병아리 감별사는 규칙을 외워서가 아니라 수천 번 고르고 바로 정답을 확인하면서 감을 기른다. 독해에도 이런 '감'이 있다. 잘 읽는 사람은 문단을 보자마자 "이건 주장, 이건 예시"를 알아챈다. 그렇다면 **문단 역할을 짧게 많이 고르고 바로 피드백을 받는 훈련으로 독해 역량을 기를 수 있을까?**
출처: 루프 4 통찰 공작소 v0 팀 종합의 구현물 아이디어 1번(`loops/04-insight-workshop/runs/v0/synthesis.md`). 이 감별기는 공작소가 낸 통찰을 현실에서 시험하는 일도 겸한다.

## 누구를 위한 무엇
- 먼저 정웅 본인. 책을 읽을 때 글의 뼈대(주장·근거·예시·전환)를 더 빨리, 더 정확히 잡도록 돕는다.
- 형태: 단일 HTML 파일. 서버도 API 키도 쓰지 않는다. 기록은 브라우저(localStorage)에 남긴다.

## 선행 연구 (기획에 쓴 것)
| 출처 | 가져온 것 |

| Kellman 연구실 지각 학습 모듈(PLM) | 설명보다 **짧은 분류 문제를 많이**, 범주 안팎의 다양한 사례로. 효과는 두 가지: 무엇을 봐야 하는지 '발견'하기, 더 빠르고 자동으로 보는 '유창성'. 수학·의학에서는 통했지만 **글 읽기에 쓴 연구는 찾지 못했다** → 이 감별기가 새로 시험하는 지점 |

## 전체 구조안 (얼개)
1. **문제 은행**: 문단과 정답 역할(주장/근거/예시/전환)과 정답 근거 단어. 쉬운 것(전형적인 문단)부터 헷갈리는 쌍(근거처럼 보이는 예시 등)까지 난이도 표시.
2. **한 문항 흐름**: 문단 표시 → 역할 고르기(제한 시간) → 확신도 고르기 → 판단을 가른 단어 클릭 → 피드백.
3. **피드백**: 정답과 정답 근거 단어를 강조한다. 확신했는데 틀리면 크게, 헷갈렸는데 맞으면 짧게(예측 오차). 점수는 보여 주지 않는다.
4. **출제 순서**: 섞어서 낸다. 기준 정답률을 넘으면 헷갈리는 쌍을 더 넣는다.
5. **말로 정리하기**: 30문항마다 "자주 틀리는 패턴" 한 줄(예: "'예를 들어'가 없는 예시를 근거로 착각함").
6. **측정**: 정답률, 응답 시간, 확신도 보정(확신 3 답의 실제 정답률), 이틀 뒤 처음 보는 문단으로 재시험.

## 성공 기준 (초안)
- 일주일 체험 뒤, 처음 보는 문단에서 정답률과 확신도 보정이 첫날보다 나아졌다.
- 실제 책 한 장을 읽을 때 뼈대가 더 빨리 보인다고 정웅이 느낀다. 느낌만이 아니라, 체험 전후에 같은 난이도의 다른 장을 읽고 구조를 적어 비교한다.

## 정웅의 읽기 답과 반영 (11/25)
- **구조 수업의 효과가 왜 사라졌나 (정웅의 가설):** 배우는 시간에만 배운 방법을 쓰고, 시간이 지나면 원래 읽던 대로 읽는다. 자동으로 몸에 붙어야 한다.
  → 반영: 앱 안의 재시험만으로는 이 가설을 시험할 수 없다. 앱에서 잘해도 실제 책을 읽을 때는 안 쓸 수 있기 때문이다. 그래서 성공 기준의 "실제 책 한 장 구조 적기(체험 전후)"가 핵심 측정이 된다.
- **분류 학습은 구조 학습과 같은가 (정웅의 질문):** 같지 않다. 구조 수업(Meyer 계열)은 글 전체의 짜임(비교·대조, 원인·결과, 문제·해결, 순서, 기술)을 가르친다. 이 감별기는 논증글 안에서 문단 하나가 하는 일(주장·근거·예시·전환)을 고르게 한다. 문단 기능은 구조의 한 조각이다. v1 후보: 문단 역할을 모아 글 전체의 뼈대 그리기(구조 수업 연구가 권한 그래픽 조직자와 같은 역할).
- **제한 시간이 없으면:** 숙고하며 판단하게 되어 바로 알아보는 감(유창성)이 붙기 어렵다. 단, 시간 압박은 "하지만이 보이면 전환" 같은 겉 단서 찍기를 부를 수 있다. 그래서 문제 은행에 단서 낱말이 없는 헷갈리는 문항을 섞었다.
- **근거 단어 클릭이 없으면:** 직감만으로 찍게 되고, 어떤 패턴으로 틀리는지 알 수 없다. 덧붙여 **"이유는 틀렸는데 답은 맞은" 경우**를 잡을 수 없다. → 반영: 정리 화면에 "맞았지만 단서를 못 가리킨 문항 수"를 넣었다.
- **구조 수업 연구에서 가져온 것:** 단서 어휘에 주목하게 하면 도움이 된다(감별기의 노란 단서와 같다). 쓰기 활동과 그래픽 조직자도 도움이 된다(v0에는 없다. 위 v1 후보와 이어진다).
- **명시적 설명의 양:** v0은 그대로 둔다(정의 한 줄, 틀렸을 때만 이유, 10문항마다 패턴 정리). 체험해 보고 정한다.

## v0 구현 메모
- 제한 시간은 막지 않는 '부드러운' 제한이다. 8초 막대가 줄어들고, 넘기면 기록에 남지만 답은 계속 고를 수 있다. 문단이 2~3문장이라 5초는 너무 짧다.
- 문단의 역할은 앞뒤 맥락에 따라 달라지므로, 문단 위에 "이 글의 중심 주장"을 함께 보여 준다.
- 말로 정리하기는 30문항이 아니라 10문항마다 한다(문제 은행이 28개뿐이라).
