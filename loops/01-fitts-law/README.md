# 루프 1 — Fitts의 법칙 (MacKenzie 1992)

## 실험 설계

- 웹 포인팅 과제(`pointing_task.html`): 좌우로 번갈아 나타나는 원형 표적을 클릭.
- A(표적 사이 거리): 150 / 300 / 450 px, W(표적 지름): 20 / 50 / 100 px → 3×3 = 9조건, 조건당 10회.
- 참가자 3명: 본인(20대, 마우스), 가족1(50대, 폰), 가족2(10대, 폰). 각 90시행 = `fitts_trials*.csv`.
- 난이도 지수 ID = log2(A/W + 1), 회귀식 MT = a + b·ID (`fitts_regression.py`, `fitts_analysis.py`).
- 시간 측정: 표적이 뜨는 순간(`showTarget`)마다 타이머가 새로 시작되고, 클릭 순간(`handleClick`)에 멈춘다. hit이든 miss든 재시도 없이 그 즉시 다음 표적으로 넘어가므로, 시행 간 시간이 누적되어 섞이는 구조적 오염은 없다.

### 2) 조건별 hit=0 vs hit=1 평균 MT

hit=0 표본이 조건당 n=1뿐이라(가족1은 0) 통계적으로 약하지만, 방향만 참고:

## 해석

시간 측정 구조상(위 참고) 시행 간 누적 오염은 처음부터 불가능했다. 그래서 hit=0을 빼도 전체 회귀 결과는 거의 안 바뀐다 — 본인은 미스 1개라 사실상 동일, 가족2는 미스 3개를 빼자 b가 231→242, IP가 4.33→4.13으로 소폭 이동했는데, 이는 측정 오염이 아니라 **어려운 조건(W=20)에서 서두르다 빠르게 놓친 시행들이 그 조건의 평균을 낮춰주고 있었기 때문**이다 — 빼면 어려운 조건이 실제보다 느려 보이게 된다. 방향은 이론과 일치하지만 시행 수(90개 중 3개)가 적어 결론을 바꿀 정도는 아니다.

가족2의 절편 a가 음수(−201~−228)로 나오는 건 오류가 아니라 회귀의 구조적 함정이다. 실제로 측정한 ID의 최솟값은 1.32이고 ID=0은 한 번도 측정하지 않았으므로, a는 관찰 구간 바깥으로 직선을 연장한 값일 뿐이다. 가족2는 W50·W100에서 A가 300→450으로 갈 때 오히려 빨라지는 비단조 구간이 2개(3명 중 가장 많음)나 있어 점들이 일직선에서 많이 벗어나 있고(R²=0.35, 가장 낮음), 이 흔들림에 직선을 억지로 맞추다 보니 왼쪽(ID=0)으로 연장했을 때 y축 아래로 내려간 것이다. `a`보다 `b`(기울기)·`IP`를 더 신뢰할 수 있는 값으로 보는 이유이기도 하다.

300→450 비단조 현상(본인·가족2 각 2칸)에 대한 가설: 300px보다 450px이 오히려 손목/팔을 더 크게, 자연스러운 궤적으로 "휙" 움직이기 편해서(짧은 거리는 미세 조정이 더 필요) 시간이 단축됐을 가능성. 다만 조건당 10회, 반복 블록 없이 한 번만 측정한 표본이라 단순 노이즈일 가능성도 배제 못 한다 — 가족1은 같은 표본 크기에서도 비단조가 전혀 없었던 게 그 방증. 이 가설을 검증하려면 조건당 반복 횟수를 늘리거나 같은 조건을 여러 블록에 걸쳐 재측정해야 한다.

## 예측 vs 실제

1. (a) "450/20이 오류 제일 많을 것" → 틀림. W=20 조건 3개(150/300/450) 모두 미스 개수 동일(1개씩). A가 커져도 이 표본 크기에서는 추가로 나빠지지 않았다.
2. (b) "같은 조건 내 hit=0/1 MT 비슷할 것" → 방향이 갈림. 가족2의 A300·A450/W20에서는 미스가 오히려 훨씬 빨랐다(서두르다 놓침). 다만 n=1이라 신뢰하긴 어렵다.
3. (c) "ID 같은 두 조건 MT 비슷할 것" → 가족1·가족2는 맞았지만(2~4%), 본인만 24% 차이로 크게 벗어났다.

## 한계

- hit=0 표본이 조건당 1개뿐이라 2단계 비교는 통계적 근거로 쓰기엔 약하다.
- 참가자 3명(그중 2명은 가족) 각 90시행뿐이라 개인차인지 진짜 현상인지 구분 안 된다.
- 조건당 반복 블록이 하나뿐이라(같은 조건을 여러 번 나눠 재측정하지 않음) 300→450 비단조 현상 같은 패턴이 진짜 모터 전략 차이인지 단순 표본 노이즈인지 이 데이터만으로는 구분할 수 없다.
