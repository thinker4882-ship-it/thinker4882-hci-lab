# 루프 2 설명서 — 숫자 추정 실험 페이지

## 1. 전체 구조와 데이터 흐름

파일은 둘이다. `questions.js`는 **실험 전에 정해진 값**을, `woa_task.html`은 **화면과 실행 중 동작**을 맡는다.

```
questions.js                       woa_task.html
(집단표, 틀린 자리, 문제 16개)  →   번호 입력 → 집단 찾기, 순서 섞기
                                        ↓
                                   [초기 화면 → 조언 결정 → 최종 화면] × 16
                                        ↓ 문제마다 records에 한 줄 추가
                                   조작 점검 화면 → 답을 모든 줄에 채움
                                        ↓
                                   CSV 표시, 복사·다운로드
                                        ↓
                                   분석 때 WOA와 오차 계산
```

핵심 구조는 **상태 + 그리기**다. `화면` 변수에 지금 단계("시작", "초기", "최종", "점검")를 적어 두고, `화면_그리기()`가 그 값을 보고 페이지를 새로 만든다. "다음" 버튼은 하나이고, `다음_누름()`이 `화면` 값에 따라 다른 일을 한다.

WOA는 페이지에서 계산하지 않는다. 페이지는 재료(초기값, 조언, 최종값)만 기록한다.

## 2. 파일·함수별 한 줄 요약

**questions.js**
- `집단표`: 참가자 번호별 확신도 표시 여부
- `틀린_자리`: 틀린 조언이 들어갈 순번
- `문제들`: 문제 16개와 정답, 조언, 확신도, 슬라이더 범위
- `점검1_보기`, `점검2_보기`: 조작 점검 보기

**woa_task.html**
- `시작하기`: 번호로 집단을 찾고 실험을 시작한다
- `섞기`: 배열을 무작위로 섞는다
- `순서_섞기`: 맞음/틀림 자리를 지키며 문제 순서를 정한다
- `문제_시작`: 다음 문제의 초기 화면으로 넘어간다
- `조언_정하기`: 보여줄 조언값을 정한다
- `슬라이더`: 슬라이더 HTML을 만든다
- `슬라이더_기록`: 움직이면 숫자를 갱신하고 움직임을 표시한다
- `보기_목록`: 객관식 보기 HTML을 만든다
- `화면_그리기`: 현재 단계에 맞는 화면을 그린다
- `시간_재기`: 화면이 뜬 뒤 지난 시간을 잰다
- `고른_보기`: 객관식에서 고른 답을 읽는다
- `다음_누름`: 값을 기록하고 다음 단계로 넘어간다
- `CSV_저장`: 기록을 CSV로 만들어 보여준다

**woa_analysis.py** (실험이 끝난 뒤 CSV를 읽는다)
- `읽기`: 여러 CSV를 한 목록으로 합친다
- `잘린_woa`: WOA를 계산해 0~1로 자른다
- `오차`: 정답과의 거리를 비율로 돌려준다
- `칸별_요약`: 표시 × 맞음/틀림 네 칸의 평균을 출력한다
- `점검_요약`: 참가자별 조작 점검 답을 출력한다
- `빠른_시행`: 최종 화면 2초 이하 + 안 움직임 시행을 센다 (빼지는 않는다)

**microworld.html**: 초기·조언·최종 슬라이더로 WOA와 오차를 바로 보는 놀이터. 실험과 독립된 파일이다.

## 3. 실행 순서대로 흐름

페이지가 열리면 `questions.js`가 먼저 읽히고, 맨 아래 `화면_그리기()`가 시작 화면을 그린다.

참가자가 번호를 넣고 시작을 누르면 `시작하기()`가 `집단표`에서 집단을 찾는다. 없는 번호면 경고만 띄우고 멈춘다. 이어서 `순서_섞기()`가 맞는 조언 12개와 틀린 조언 4개를 각각 섞고, 4·7·11·14번째 자리에 틀린 조언을 넣는다. 사람마다 문제 순서는 달라도 자리 패턴은 같다.

`문제_시작()`이 `현재`에 문제를 넣고 초기 화면을 그린다. `화면_그리기()`는 그릴 때마다 시작 시각을 적고 움직임 표시를 지운다. 슬라이더 손잡이는 범위 가운데에서 시작한다.

"다음"을 누르면 `다음_누름()`이 초기 응답값과 초기 화면 시간을 저장하고, `조언_정하기()`로 보여줄 조언을 정한다. 조언과 초기값의 차이가 답의 2% 이상이면 미리 정한 값을 그대로 쓴다. 더 가까우면 맞는 조언은 정답 ±3% 양 끝 중 초기값에서 먼 쪽으로, 틀린 조언은 정답에서 더 먼 쪽으로 답의 5%만큼 옮긴다.

최종 화면에는 내 처음 추정과 AI 조언이 보인다. 표시 집단이면 확신도도 보인다. 손잡이는 초기값에서 시작하므로, 안 건드리면 WOA는 0이다.

최종 화면에서 "다음"을 누르면 18열 중 16열이 한 줄로 `records`에 들어간다. 문제가 남았으면 다음 문제로, 16개가 끝났으면 점검 화면으로 간다. 점검 문항 2는 표시 집단에게만 보인다.

점검 답을 고르고 "다음"을 누르면 답 2개가 모든 줄 끝에 붙어 18열이 된다. `CSV_저장()`이 결과를 글상자에 보여주고 복사·다운로드 버튼을 단다.

## 4. 코드

한 줄씩 읽어 볼 함수는 이 둘이다. 나머지 코드는 `woa_task.html`에 있다.

```js
function 조언_정하기(q, 초기값) {
  if (Math.abs(q.preset - 초기값) / q.answer >= 0.02) return q.preset;
  if (q.correct) {
    const 위 = Math.floor(q.answer * 1.03 / q.step) * q.step;
    const 아래 = Math.ceil(q.answer * 0.97 / q.step) * q.step;
    return Math.abs(위 - 초기값) >= Math.abs(아래 - 초기값) ? 위 : 아래;
  }
  const 방향 = q.preset > q.answer ? 1 : -1;
  return Math.round((q.preset + 방향 * q.answer * 0.05) / q.step) * q.step;
}
```

```js
function 다음_누름() {
  if (화면 === "초기") {
    현재.초기 = Number(document.getElementById("슬라이더").value);
    초기시간 = 시간_재기();
    현재.보여줄조언 = 조언_정하기(현재, 현재.초기);
    화면 = "최종";
    화면_그리기();
  } else if (화면 === "최종") {
    const 최종 = Number(document.getElementById("슬라이더").value);
    records.push([참가자, 현재.id, 위치 + 1, 표시집단, 현재.conf, 현재.answer, 현재.초기, 최종, 현재.preset,
      현재.보여줄조언, 현재.correct, 현재.min, 현재.max, 초기시간, 시간_재기(), 움직임]);
    위치 += 1;
    if (위치 < 순서.length) { 문제_시작(); } else { 화면 = "점검"; 화면_그리기(); }
  } else if (화면 === "점검") {
    const 답1 = 고른_보기("점검1");
    const 답2 = 표시집단 ? 고른_보기("점검2") : "해당없음";
    if (!답1 || !답2) { alert("모든 질문에 답해 주세요."); return; }
    records.forEach(줄 => 줄.push(답1, 답2));
    CSV_저장();
  }
}
```
