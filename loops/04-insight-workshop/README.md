# 루프 4 — 통찰 공작소 (멀티 에이전트 집단 지성)

## 문제의식
혼자서는 떠올리지 못할 통찰을, 서로 다른 배경을 가진 에이전트들의 토론으로 끌어낼 수 있을까?
여러 에이전트에게 검토를 맡겨 본 경험은 "신기하지만 기대만큼 탁월하진 않았다". 같은 모델에 이름표만 바꿔 붙이면 진짜 다양성이 생기지 않는다는 것이 가장 유력한 이유다.

## 누구를 위한 무엇
- 정웅이 독서 노트의 통찰을 넓히거나 막힌 문제를 풀 때 쓰는 도구.
- 시작과 최종 판단은 정웅이 한다. 노트 원문(Notion)은 레포에 넣지 않고, 도구만 공개한다.
- 형태: Claude Code 안에서 메인 에이전트(지휘자)가 서브에이전트들을 지휘한다. API 키도 추가 비용도 없다.

## 선행 연구 (기획에 쓴 것, 원문 확인은 진행하면서)
| 출처 | 가져온 것 |
|---|---|
| Si et al. (2024) LLM 연구 아이디어 실험 | LLM 아이디어는 참신하다는 평가를 받았지만 다양성이 붕괴했고, LLM 심사위원은 믿을 수 없었다 |
| Nemeth et al. (2001) | 역할로 맡긴 반대보다 진짜 반대가 독창성을 더 끌어낸다 → 반박가에게 실제 반대 증거를 쥐여 준다 |
| Hong & Page (2004) | 다양성의 핵심은 관점과 문제 푸는 요령의 차이 → 에이전트마다 다른 자료로 조사하게 한다 |
| 델파이 기법, 서로위키 『군중의 지혜』 | 독립성: 남의 답과 정웅의 의견을 보기 전에 먼저 각자 답한다 |
| 허깅페이스 사건, 리만 가설 Lean 인증 (2026) | 판정자(검증기)가 약하면 보상 해킹이 생기고, 강하면 돌파구가 된다 |

## 설계 원칙
1. **다양성은 이름표가 아니라 각자 가진 지식에서 나온다.** 분야별 역할을 나누되, 각 역할이 다른 자료를 찾아 근거로 쓴다. 모델도 섞는다(Opus·Sonnet·Haiku).
2. **독립 → 반박 → 종합.** 1라운드는 서로의 답을 보지 않는다.
3. **판정은 블라인드로, 마지막 판정은 현실이 한다.** 팀 결과와 비교군 결과를 가린 채 정웅이 고르고, 고른 결과를 일주일 안에 시험할 수 있는 구현물로 바꿔 체험한다.

## 성공 기준
**팀 결과가, 같은 모델 구성으로 에이전트 하나를 여러 번 돌려 그중 최고를 고른 결과보다 나은가?** (블라인드 비교)
여기에 정웅이 먼저 혼자 써 둔 답도 세 번째 비교 대상으로 둔다. "나 혼자서는 떠올리지 못했다"를 확인하기 위해서다.

## v0 실행 (2026-11-24)
**화두**: 시행착오 피드백으로 암묵지를 기르는 원리(병아리 감별사, 비행기 식별 사례)를 내 학습을 돕는 AI 교육 시스템에 어떻게 적용할까?
- (가) 답이 분명하지 않은 학습에도 통하는가?
- (나) 효과적으로 통하는 영역과 통하지 않는 영역을 구분할 수 있는가?
- (다) 이것을 효과적인 교육 시스템으로 어떻게 구축하는가?

몰입을 적용한 교육 시스템은 별도 화두로 v1에서 돌린다. 공작소가 다른 화두에서도 통하는지 보는 재현 시험을 겸한다.

| 팀 | 렌즈 | 모델 |
|---|---|---|
| 1 | 인지과학: 암묵지, 지각 학습, 피드백 | Opus |
| 2 | 기계학습: 시행착오 학습, 정답이 없을 때의 학습 신호 | Sonnet |
| 3 | 교육공학: 교육 시스템 설계, 피드백 시점, 개인 맞춤 | Sonnet |
| 4 | 반박가: 이 원리와 ML 비유가 실패하는 곳의 실제 증거 | Haiku |

- 비교군: 렌즈 없이 같은 화두만 받은 에이전트 4개(모델 구성은 팀과 같음). 그중 최고는 별도 심사 에이전트가 고른다.
- 진행: ① 독립 답변 → ② 서로 읽고 반박 → ③ 지휘자가 종합: "통하는 영역 지도 + 일주일 안에 시험할 구현물 3개".
- 정웅의 의견(예: "암묵지에는 말로 다 설명할 수 없는 측면이 있다")은 에이전트들에게 보여 주지 않는다.

## 결과·회고
### v0 판정 (2026-11-25) — 성공 기준 통과 (판정 1회)
- 정답 키: **A = 비교군 최고, B = 팀 종합**. 정웅은 **B**를 골랐다. 이유: "통찰력은 B가 압도적. 답을 바로 채점할 수 있는 층과 그렇지 않은 층을 나눈 것이 핵심인데, A는 그 차이를 구분하지 못했다. 다만 B는 설명이 불친절하다." 자기 답과 상세 평은 `runs/v0/judgment.md`에 있다.
- **승부를 가른 통찰은 2라운드에서 나왔다.** '두 층'과 '예측 오차에 맞춘 피드백'은 1라운드와 비교군 어디에도 없고, 2라운드 파일(team2·3·4)에만 있다. 1라운드는 다양성이 무너졌지만(아래 관찰 메모), "결합해야만 나오는 것"을 요구한 반박 라운드가 차이를 만들었다.
- **정웅 혼자 쓴 답과 비교하면:** 정웅은 "덜 효과적인 영역이 있다"까지 닿았지만, 그 경계를 두 층으로 나누는 것, 예측 오차, 확신도 보정, 섞어 보기의 착각은 떠올리지 못했다고 직접 평가했다. 두 결과 모두 "혼자서는 못 떠올린" 것을 줬다.
- **팀 종합의 약점:** 설명이 어렵다("가리키기"가 무엇인지, 취향 복제를 어떻게 해결하는지). 결합 아이디어가 늘수록 문장이 압축되는 경향이 있다.
- **한계:** 판정자 1명, 화두 1개, 1회 실행이다. 정웅은 설계를 알고 있었지만 어느 쪽이 팀인지는 몰랐다.

### 멀티 에이전트의 효능 — 루프 4의 핵심 질문에 대한 v0의 답
**확인된 것:** 서로의 답을 읽고 반박·결합하는 멀티 에이전트 팀이, 혼자 답한 에이전트 4개 중 최고보다 더 깊은 통찰을 냈다(블라인드 판정). 정웅은 그 차이를 "통찰력은 압도적, 논리도 탄탄하다"고 평했다. 판정에서 가장 높게 친 통찰 두 가지는 반박 라운드에서만 나왔다. 혼자 쓴 답(비교군)에도, 1라운드의 독립 답에도 없었다.

**그 효능이 어디서 왔나:** 역할 이름표(렌즈)는 아니었다. 1라운드에서는 렌즈를 받은 팀원도 비교군과 거의 같은 근거를 들고 왔다. 차이는 **상호작용**, 곧 남의 답을 읽고 "합의는 반복하지 말고 결합해야만 나오는 것을 내라"는 조건으로 다시 쓴 단계에서 생겼다. 멀티 에이전트의 힘은 '여러 명'이 아니라 '서로 부딪히는 구조'에 있었다는 가설이 선다.

**아직 확인 안 된 것 (v1에서 볼 것):**
- 재현: 다른 화두(v1 몰입 교육)에서도 팀이 이기나?
- 양 대 구조: 팀은 남의 답을 읽은 만큼 더 많은 재료를 봤다. 에이전트 하나에게 자기 답을 두 번 고치게 하는 비교군을 추가하면, 이득이 '부딪힘'에서 오는지 '고쳐 쓰기 횟수'에서 오는지 가를 수 있다.
- 모델 섞기(Opus·Sonnet·Haiku)의 효과는 따로 재지 않았다.

### v1에 넣을 개선
1. 종합 끝에 **'쉬운 말 다듬기' 단계**를 넣는다. 개념마다 예시 하나와 "학습자 화면에서는 이렇게 보인다"를 붙인다.
2. 비교군에서 나온 좋은 조각(틀린 패턴을 말로 정리하기, 섞어 보기, 확신도 보정)은 팀 종합에 흡수할 수 있었다. 지휘자가 종합할 때 비교군 최고도 재료로 읽게 할지 검토한다(그러면 블라인드 비교 설계가 바뀌므로 판정용 사본은 따로 둔다).
3. 다양성은 1라운드부터 강제한다. 2라운드가 효과 있었으니, 1라운드에도 "다른 팀이 들고 올 법한 흔한 근거는 금지" 같은 조건을 시험해 본다.

### 남은 질문 (정웅의 판정에서 나옴, 구현물·v1 재료)
- 섞어 보기가 더 효과적인데도 학습자는 왜 몰아 보기를 더 효과적이라고 느끼나? 시스템에 어떻게 넣나?
- 정답이 없는 과제에서 '나중에 드러나는 결과'나 '내 판단의 일관성'을 채점 신호로 쓴다는 것은 구체적으로 어떤 화면·흐름인가?
- 글쓰기, 긴 코드 구조 파악, 딥러닝 깊은 이해 같은 생성 과제도 변별 과제로 쪼갤 수 있나? 쪼개면 카너만이 말한 한계를 넘나?
- 자전거 타기 같은 운동 기술, 명시적 지식 이해에도 이 방식이 통하나?

관찰 메모 (판정 전, Claude): 렌즈를 받은 팀원이든 비교군이든 1라운드에서 거의 같은 근거를 들고 왔다(Kahneman & Klein, Hogarth, Biederman 반전, Kornell & Bjork). 같은 모델 계열의 다양성 붕괴로 보인다. 2라운드에서 "합의는 반복 금지, 결합해야만 나오는 것"을 요구하자 새 근거(Ahissar & Hochstein, 언어 그늘 효과)와 결합 아이디어(채점 위원회, 편향 복제 지수, 두 층 은행)가 나왔다.
