# 화두 (v0)

참조 사례 두 가지:
- **병아리 감별사**: 전문 감별사는 거의 똑같이 생긴 병아리의 암수를 기가 막히게 구분하지만, 어떤 시각적 단서로 구분하는지는 설명하지 못한다. 학습 방식: 제자가 병아리를 살펴보고 추측하면, 스승은 맞았는지 틀렸는지만 알려 준다. 이걸 반복하면 제자도 전문가가 된다.
- **비행기 식별**: 탁월한 식별가들은 자신이 어떻게 비행기를 식별하는지 설명하지 못했다. 이론적 설명으로 가르치는 방식은 실패했다. 반면 신참이 추측하고 전문가가 정답을 알려 주는 방식을 반복하자 신참도 같은 솜씨를 갖게 되었다.

이건 머신러닝의 학습 방식과 비슷해 보인다. 일단 추측하고, 채점받고, 파라미터를 조정하고, 다시 시도한다.

- (가) 위 사례들은 답이 분명한 과제다. 답이 분명하지 않은 학습에도 이 원리가 통하는가?
- (나) 이 원리가 효과적으로 통하는 영역과 통하지 않는 영역을 구분할 수 있는가? 구분 기준은?
- (다) 이것을 실제로 효과적인 교육 시스템으로 어떻게 구축하는가?
